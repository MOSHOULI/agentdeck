# MCP 开关预检与备份边界

简体中文 | [English](MCP-SAFETY.md)

这是开发分支修复，**尚未随正式安装包发布**。它只调整桌面
MCP 开关的备份顺序，不修改注册表内容、包版本或发布产物。批量 MCP 同步
（`mcp::sync`）保持不变。

## 修改内容

此前，`toggle_mcp_for_agent` 在核心验证开关请求前调用 Git 备份。因此，
不支持的目标或无效配置可能在备份、密钥库或仓库初始化已经开始后才被拒绝。

桌面命令现在调用 `mcp::toggle_with_backup`。核心在持有共享的**进程内**
配置写锁期间依次执行：

1. 解析 Agent 目标；启用时还需取得未禁用的服务器定义。检查目标路径，
   读取现有文本或记录文件不存在，再用现有解析器与转换逻辑准备结果。
2. 仅在准备成功后调用一次备份回调。有效但无需修改的请求仍调用备份，
   保留原有桌面行为。
3. 复查目标的存在状态、内容与路径类型。发现冲突时返回错误，不覆盖外部修改。
4. 保存已准备好的结果，保留现有本地恢复副本行为。备份后不重新读取注册表，
   也不重新生成修改内容。

私有 `PreparedToggle` 固定目标路径、原始状态及输出。备份回调不能重入配置
写操作，因为整个过程都持有写锁。核心 `mcp::toggle` API 复用此准备流程，
但自身不执行 Git 备份。

## 失败与兼容性边界

- **预检拒绝：** 不调用 Git 备份回调，不创建本次 MCP 本地恢复副本，也不写
  目标配置。包括不支持的目标（如 OpenCode）、启用不存在或已禁用的服务器、
  不允许的启动命令、不支持的格式、解析或转换失败，以及不合规的目标路径。
  路径必须解析为带文件名且不含 `..` 组成部分的绝对路径；已存在的路径组成
  部分不能是符号链接，已有目标必须是普通文件，已有父路径必须是目录。这是拒绝不安全
  或无法解析的路径，不是通用路径规范化。
- 这些是现有格式解析/转换检查及目标路径检查，并非对所有外部 Agent 配置
  schema 的完整验证。关闭操作仍允许按名称移除已禁用或已从注册表删除的
  服务器，无需取得可启用的服务器定义。
- **备份失败：** 返回错误，停止目标写入和本次 MCP 本地恢复副本步骤。
  备份操作本身可能已留下文件。
- **备份后的冲突：** 已完成的备份可以保留。复查会区分文件原本不存在与
  新建的空文件，并拒绝检测到的内容或路径类型变化。这不是跨进程锁或原子
  比较替换；外部写入仍可能发生在最后一次检查与文件替换之间。
- 注册表读取本身会创建/使用 `registry-update.lock`，也可能恢复中断的
  注册表更新。因此，预检拒绝**不保证零文件系统活动，也不保证不存在
  `~/.agentdeck/` 目录**。

开关只修改配置，不安装、启动、停止或连接 MCP 服务器，成功也不代表真实服务
可用。本地恢复副本可能含凭据，参见 [数据与恢复边界](../README.md#数据与恢复边界)。

## 验证范围

回归测试使用隔离的合成输入，核心备份顺序测试注入假备份回调。原有顺序通过假备份标记复现，
并未执行真实密钥库/Git 备份。本次增量未测试真实用户配置、外部 Agent、
在线 MCP 服务或桌面 GUI。合成测试不能证明桌面端到端流程或 Windows
受保护备份行为已经通过验证。
