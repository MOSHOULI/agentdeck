# MCP 配置变更预览

简体中文 | [English](MCP-PREVIEW.md)

开发中功能，尚未随正式安装包发布。

桌面 MCP 面板将检查变更与实际应用分开。点击 Agent 开关后先生成预览，不会立即
备份或写入 Agent 配置。检查服务、Agent、目标文件、格式、加入/移除操作、文件
是否存在以及文件内容是否会变化，再明确确认。取消不会改动配置。

这里提供的是**变更摘要，不是完整配置差异**。预览刻意不返回配置内容、凭据或
生成后的文件。JSON/YAML 写入器可能重新序列化文件，影响格式或注释，摘要不会
显示这些差异。启用会按注册表定义新增或替换同名服务器的整个配置块，其中的
自定义字段可能丢失。本次不为 profile 应用或 CLI 批量同步增加预览。

## 过期检查与安全边界

预览携带本次操作的 revision，桌面确认时传回后端。后端在共享的进程内配置写锁
下重新准备操作，目标、配置内容或相关注册表定义变化时，会在备份前拒绝。过期
预览需要重新检查，不会静默套用到新状态。revision 仅用于检测过期，不是认证或
授权凭证，不应记录到日志或公开。已有直接开关 API 继续保留。

明确确认且预览匹配后，才进入既有备份与写入流程。备份失败会阻止配置写入，但
备份自身可能已创建文件。备份后再次检查目标，拒绝检测到的外部变更。此机制不
是跨进程事务：最后检查到原子替换之间，外部写入仍可能产生竞态。

预览不会运行 Git 备份、初始化密钥库、建立 MCP 本地恢复副本、写目标配置或
执行/连接服务。注册表加载仍可能创建锁文件并恢复中断的注册表更新，因此不能
承诺完全没有文件系统活动。成功只说明配置变更，不证明服务健康、认证或连接成功。

## 验证范围

回归使用合成配置和模拟 IPC，不能替代真实 Agent 配置、在线 MCP 服务和 Windows
桌面手工验收。既有恢复与并发限制见 [MCP 备份边界](MCP-SAFETY.zh-CN.md)。
